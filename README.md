# Standalone PixelDiT priming experiment

This is Sophia's separate experiment based on Hudson's public code.
Code, checkpoints, and logs belong in this new folder. Hudson's original
checkout and GitHub repository are not modified.

See [PIXELDIT_EXPERIMENT.md](PIXELDIT_EXPERIMENT.md) for the two-stage plan,
validation, and four-H100 UCL SGE instructions.

The suggested cluster folder is
`/SAN/intelsys/imagenet_mmd_flow/pixeldit_priming_cifar10/`.
Its outputs live in `results/cifar/` beneath that folder.

[BASELINE_README.md](BASELINE_README.md) preserves documentation from the
source repository for reference; its old launchers and machine-specific paths
are not the instructions for this experiment.
